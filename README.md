# CS50W: Web Programming with Python and JavaScript

Este repositório contém todos os projetos desenvolvidos por mim ao longo do curso CS50W, oferecido pela Universidade de Harvard. O objetivo principal é documentar minha evolução no desenvolvimento web e consolidação de boas práticas.

## Projetos Concluídos

### 📁 [Project 0: Search](./project0)
Uma recriação do front-end do Google, incluindo a Pesquisa Principal, Pesquisa de Imagens e Pesquisa Avançada.
- **Tecnologias:** HTML5, CSS3 e Flexbox.
- **O que aprendi:** 
  - Estruturação semântica do HTML.
  - Alinhamento avançado de elementos utilizando CSS Flexbox (sem depender de tabelas).
  - Compreensão do funcionamento de requisições GET e envio de parâmetros via formulários (`q`, `tbm=isch`, etc.).
  - Uso de campos ocultos (`type="hidden"`) para manipulação de rotas do lado do cliente.
